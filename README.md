# The Power to Stop

Entry for the make.fun bounty **"The poem about stopping"**
(`the-poem-about-stopping-20261121-1927`).

A short rhymed poem about agency — the power to stop and to stay. The poem
lifts the kettle off the flame: the boil can wait, the steam thins and slows,
and the last line pours the silence like tea. Stopping here is not waiting
the rush out — it is ending it, on purpose, and staying with what is left.

`main.py` (Python 3.13) writes the poem to `/output/entry.txt`
(1–280 Unicode code points, deterministic across runs).
